GENERATED by `tools/build_import.py`. Don't edit it here; it is rebuilt on every build.

Do the steps in this order. Objects in step 2 must exist before the import, because the imported code uses them.

- [ ] **Standard**: TON (usually already in the project)
- [ ] **CXA_DriveUtil**: MB_PowerSupplyDriveIntegrated

## 2. Create these objects by hand (the converter can't do interfaces, methods or properties)

### `I_StateClient` (interface)

> INTERFACE: I_StateClient Standard way for a unit to talk to its state client. Add the two methods below as child objects of the interface in the device tree.

Add Object → Interface `I_StateClient`. Then, for each method file, right-click the interface → Add Object → Method (name from the file) and paste the declaration.

Paste each file into the pane its title names:

- [ ] `I_StateClient/01_Interface_declaration.st`: Interface declaration
- [ ] `I_StateClient/02_Method_I_StateClient_Request_declaration_only.st`: Method I_StateClient.Request (declaration only)
- [ ] `I_StateClient/03_Method_I_StateClient_Report_declaration_only.st`: Method I_StateClient.Report (declaration only)

### `FB_StateClient` (function block)

> FUNCTION_BLOCK: FB_StateClient The actual client. Holds one unit's requests, echo and done for FB_StateManager. Instances live in GVL_State.aClients; units reach them only through FB_StateRequest. Child objects: methods Request and Report, property Data (Get only).

Add Object → POU → Function Block `FB_StateClient` with *Implements* `I_StateClient`. Paste the declaration and implementation. If the IDE generated method stubs from the interface, paste into them; otherwise right-click the FB → Add Object → Method / Property. For a property, delete the Set accessor unless a Set file is given.

Paste each file into the pane its title names:

- [ ] `FB_StateClient/01_Declaration.st`: Declaration
- [ ] `FB_StateClient/02_Implementation.st`: Implementation
- [ ] `FB_StateClient/03_Method_FB_StateClient_Request_declaration.st`: Method FB_StateClient.Request: declaration
- [ ] `FB_StateClient/04_Method_FB_StateClient_Request_implementation.st`: Method FB_StateClient.Request: implementation
- [ ] `FB_StateClient/05_Method_FB_StateClient_Report_declaration.st`: Method FB_StateClient.Report: declaration
- [ ] `FB_StateClient/06_Method_FB_StateClient_Report_implementation.st`: Method FB_StateClient.Report: implementation
- [ ] `FB_StateClient/07_Property_FB_StateClient_Data_declaration.st`: Property FB_StateClient.Data: declaration
- [ ] `FB_StateClient/08_Property_FB_StateClient_Data_Get_implementation.st`: Property FB_StateClient.Data, Get: implementation
